# Project screenshots (optional)

Drop images here (for example `directv/home.png`) and list them on the role in `docs/data.js`:

```js
media: [{ src: "media/directv/home.png", caption: "Home screen on phone" }]
```

They appear in a "Screens" gallery inside that project's detail overlay. Use only images you have the right to share
(your own screenshots or public store listings).
